# 英语启蒙第二册：中阶启蒙 My English Adventure

> 面向完成第一册的小朋友（6–10岁），在 120 个启蒙词基础上，扩展动作动词、情绪形容词、时间词、居家/出行/自然场景，并贯穿 **Can you ___? / Do you like ___? / Where is ___?** 三大核心句型。

---

## 一、衔接第一册的设计原则

### 第一册已掌握词（120词，供螺旋复现）

| 模块 | 代表词 |
|------|--------|
| 问候 | hello / hi / bye / I / my / you / good / morning |
| 数字 | one–twelve / twenty |
| 颜色 | red / blue / yellow / green / orange / pink / purple / white / black / brown |
| 动物 | cat / dog / bird / fish / duck / frog / lion / bear / rabbit / monkey / elephant / panda |
| 身体 | head / eye / nose / mouth / ear / hand / foot / leg / arm / hair / face / tooth |
| 家庭 | mom / dad / baby / sister / brother / grandma / grandpa / family / home / love |
| 食物 | apple / banana / rice / bread / egg / milk / water / cake / cookie / juice / soup |
| 学校 | school / class / teacher / student / book / pen / pencil / bag / desk / chair / friend / play |
| 形状 | circle / square / triangle / star / heart / big / small / long / round |
| 天气 | sun / sunny / rain / rainy / wind / snow / hot / cold / spring / summer / autumn / winter |

### 三大螺旋策略

1. **词汇复现**：每章例句中至少出现 2–3 个第一册或前几章已学词
2. **句型递进**：第 1–3 章用简单陈述句，第 4–6 章引入疑问句，第 7–10 章混合使用
3. **主题串联**：动词（第1–2章）→ 情绪（第3章）→ 时间（第4章）→ 场景（第5–10章），前章动词自然出现在后章场景中

## 二、课程总览

**课程名称：** 英语启蒙·第二册 My English Adventure
**适用年龄：** 6–10 岁
**前置要求：** 完成第一册（约掌握 120 词）
**总词量：** 118 个新词
**章节数：** 10 章
**每章词量：** 10–12 词
**预计完课时间：** 约 60–90 天

### 章节路线图

```
第1章 基础动作 → 第2章 更多动作 → 第3章 情绪感受 → 第4章 时间日程
       ↓ 动词在后续场景中持续复现 ↓
第5章 我的家 → 第6章 衣着穿搭 → 第7章 交通出行 → 第8章 自然风景
       ↓ 综合场景句型强化 ↓
第9章 运动游戏 → 第10章 城镇生活
```

**三大核心句型分布：**

| 句型 | 重点引入章节 |
|------|------------|
| `Can you ___?` | 第 1–2 章（Can you run / swim?） |
| `Do you like ___?` | 第 3–4 章（Do you like dancing?） |
| `Where is ___?` | 第 5、10 章（Where is my room? / Where is the shop?） |

## 七、录入优先级建议

1. **先录入第 1–3 章**（动作 + 情绪）作为内测，与第一册平滑衔接
2. 第 4–6 章（时间 / 家 / 衣服）场景词配生活化图片效果最佳
3. 第 7–10 章可批量处理，配套城镇/自然插图
4. 每个新词需要：配图 + 音频 + 例句（例句中含已学旧词，强化螺旋效果）

## 八、第三册方向（预告）

- **Phonics 系统**：自然拼读 A–Z，CVC → CVCe → 常见字母组合（ai / ee / oa...）
- **基础句型扩展**：There is / There are... / I want to... / Let me...
- **数量与比较**：more / less / bigger / smaller / the biggest
- **简单过去时入门**：was / were / had / went（高频不规则动词）
- **社交对话**：打电话 / 问路完整对话 / 购物情景
